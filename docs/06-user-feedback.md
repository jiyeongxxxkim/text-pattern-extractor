- 테스터: 인스타그램 공구(공동구매) 운영 지인 1인. 고객 DM에서 계좌번호·연락처·예약 날짜를 수동으로 옮겨 적는 업무를 실제로 자주 함 — 이 도구의 실사용 시나리오에 가장 가까운 인물
- 방식: 배포 URL(https://jiyeongxxxkim.github.io/text-pattern-extractor/)을 SNS(카카오톡)로 전달, 자유 사용 후 텍스트 피드백 수신
