- 완료 기준: 상대 날짜 표현을 `YYYY-MM-DD HH:mm` 포맷으로 변환

## M4 — AI QA 파이프라인
- 산출물: `qa/run-qa.mjs`(검증 스크립트), `qa/cases/*.json`(케이스), 최초 QA 리포트
  - 케이스 생성은 별도 스크립트(`generate-cases.mjs`)가 아니라 Claude Code 세션의 블라인드 서브에이전트로 수행(D-007). 케이스를 새로 생성하려면 스크립트 실행이 아니라 Claude Code 세션 호출이 필요
- 완료 기준: 엣지케이스 100개 생성, 정답률 산출, 실패 케이스 분석 후 로직 수정 1회 이상 반영, 정답률 95% 이상 달성
- **실행 결과 (2026-09-18)**: 케이스 100개(계좌34/날짜33/해시태그33) 생성, 계좌 97.06% · 날짜 100% 달성. 해시태그는 4회 반복 개선 후에도 60~73% 구간에서 정체 — 형태소 분석기 없이는 넘을 수 없는 구조적 한계로 판단하고 목표치를 낮춰 종료(D-010). 전체 통합 정답률은 실행 시점 스냅샷 기준 약 86~90%(D-011 참조 — AI 채점 특성상 재실행마다 소폭 변동)
