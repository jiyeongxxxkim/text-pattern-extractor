# 프로젝트 헌장 (Project Charter)

- 작성일: 2026-09-18
- 버전: v0.1 (계획 확정 단계)

## 1. 프로젝트명
비정형 텍스트 패턴 추출기 (가칭)

## 2. 목적
서버 비용 없이 프론트엔드 단에서 정규식과 문자열 알고리즘만으로 비정형 텍스트를 처리하고, AI를 활용해 극단적인 입력 케이스에 대한 방어력을 검증하는 개발·QA 파이프라인을 구축한다.

## 3. 범위 (In Scope)
1. 오타 교정 및 계좌번호 추출
2. 조사 제거 기반 해시태그 생성
3. 자연어 날짜 표현의 정형 포맷 변환
4. AI 기반 엣지케이스 자동 생성 및 정답률 검증 파이프라인

## 4. 비범위 (Out of Scope)
1. 서비스 내부에 AI API를 연동하는 기능 (AI는 개발 단계의 QA 도구로만 사용)
2. 서버·데이터베이스 구성
3. 사용자 인증, 다국어 지원

## 5. 배포 환경
- 플랫폼: GitHub Pages (D-002)
- 형태: 정적 단일 페이지

## 6. 성공 기준
1. AI 생성 엣지케이스 100개 이상에 대해 정답률 95% 이상 달성
2. 계좌번호·날짜 추출 결과가 시스템 오류(NaN, undefined, 예외 발생) 없이 반환됨
3. 정답률 변화 이력이 CHANGELOG에 버전별로 기록됨

## 7. 이해관계자
- 개발자 겸 QA 담당: 프로젝트 소유자 본인 (1인 프로젝트)
